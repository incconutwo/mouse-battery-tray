# Security policy

## Supported version

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Do not disclose an unpatched vulnerability in a public issue.

The application reads local HID input reports from compatible USB receivers,
draws a notification-area icon, and optionally manages its own per-user Windows
startup value. It does not collect telemetry or transmit device data.
